# Product Images

Add your product photos here. The HTML expects images with these naming conventions:

## Item Photo Files

- **drums_1.jpg** - Electronic drum kit (main photo)
- **drums_2.jpg** - Electronic drum kit (alternate)
- **dresser_1.jpg** - Dresser with mirror (main photo)
- **dresser_2.jpg** - Dresser with mirror (alternate)
- **nightstand_1.jpg** - Nightstand + lamp (main photo)
- **nightstand_2.jpg** - Nightstand + lamp (alternate)
- **beans_1.jpg** - Bean bag chairs (main photo)
- **beans_2.jpg** - Bean bag chairs (alternate)
- **chair_1.jpg** - Patio chair (main photo)
- **chair_2.jpg** - Patio chair (alternate)

## Adding Images

1. Place your JPG or PNG images in this folder
2. Update the `photos` arrays in `index.html` script section if file names differ
3. Commit and push to deploy via Cloudflare Pages
